# 端到端任务时序图

> [!abstract] 图示范围
> 展示 iPhone 获取多个项目、选择 Codex 会话并执行一个 Turn 的 MVP 完整路径。Relay 全程只转发消息。

> [!warning] 仅描述当前 MVP
> 本页不是下一阶段的实现蓝图。目标架构已经改为客户端 HTTPS + Session/Run SSE、PostgreSQL Runtime、Redis 实时结果层和 Agent SQLite 重放，见 [[可靠多端会话与运行时控制面升级方案]]。旧 MVP 未被迁移前，本页继续作为现状证据保留。

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant I as iPhone App
    participant R as Relay Server
    participant M as Mac Agent
    participant W as Workspace Catalog
    participant C as Codex App Server
    participant G as Git Project

    M->>C: 启动 stdio app-server
    M->>C: initialize / initialized
    M->>R: WebSocket /ws/agent
    M->>R: agent.hello(idle)
    I->>R: WebSocket /ws/app
    R-->>I: agent.hello(idle)

    I->>R: project.list
    R->>M: project.list
    M->>W: 扫描允许的 workspace roots
    W-->>M: Git projects + stable project_id
    M->>C: thread/list(cwd) 统计会话
    M-->>R: project.snapshot
    R-->>I: project.snapshot

    U->>I: 选择 Project
    I->>R: thread.list(project_id)
    R->>M: thread.list(project_id)
    M->>C: thread/list(cwd=project.path)
    C-->>M: Codex Threads
    M-->>R: thread.snapshot
    R-->>I: thread.snapshot

    U->>I: 新建或选择 Thread，发送 prompt
    I->>R: turn.start(project_id, thread_id?, prompt)
    alt Mac 在线且空闲
        R->>M: 原样转发 turn.start
        M->>W: project_id → 受控本地路径
        alt 新会话
            M->>C: thread/start(cwd)
        else 继续会话
            M->>C: 校验 thread/list(cwd)
            M->>C: thread/resume(thread_id, cwd)
        end
        M->>C: turn/start(thread_id, prompt)
        C-->>M: thread_id + turn_id
        M-->>R: turn.started
        R-->>I: turn.started
        loop Codex 执行
            C-->>M: assistant delta / command output
            M-->>R: turn.output
            R-->>I: turn.output
        end
        C-->>M: turn/completed
        M->>G: 收集 status / diff
        M-->>R: turn.completed / turn.failed
        R-->>I: 转发终态
    else Mac 离线
        R-->>I: turn.rejected(AGENT_OFFLINE)
    else Mac 正在执行
        M-->>R: turn.rejected(AGENT_BUSY)
        R-->>I: turn.rejected(AGENT_BUSY)
    end
```

## 中断分支

```mermaid
sequenceDiagram

    participant R as Relay

    I->>R: turn.interrupt(thread_id, turn_id)
    R->>M: turn.interrupt
    M->>C: turn/interrupt
    C-->>M: turn/completed(status=interrupted)
    M-->>R: turn.interrupted
    R-->>I: turn.interrupted
```

## 关键边界

- Relay 不读取 `project_id` 对应路径，也不调用 Codex。
- Mac Agent 是路径授权的最终边界，项目不在 Catalog 中就拒绝。
- Thread 归属通过 Codex 返回的 `cwd` 校验，不能跨项目恢复。
- MVP 不持久化业务 Task；Codex Thread 历史仍由 Codex 自己保存。
- 断线恢复使用 `project.list`、`thread.list` 和 `turn.snapshot`，不保证完整日志重放。
