# ADR-002 设备使用公钥身份

## 状态

已接受。

## 背景

Mac Agent 拥有修改源代码和启动本地进程的能力。仅使用一个长期 Bearer Token 虽然实现简单，但 Token 复制后可在其他机器冒充设备，泄露检测和安全轮换也较弱。

## 决策

- Agent 首次运行生成 Ed25519 密钥对。
- 私钥保存在 macOS Keychain，Relay 只保存公钥和指纹。
- 首次绑定使用短期一次性配对码，由已登录用户明确确认。
- 每次 WebSocket 连接使用 Relay nonce 完成挑战签名。
- 设备撤销后公钥永久失效，重新接入必须重新 enrollment。

## 结果

正向结果：Relay 无需保存可冒充设备的共享秘密；设备凭据难以从普通配置文件复制；挑战机制可抵抗简单重放；撤销与密钥轮换边界清晰。

代价：需要 Keychain 集成、签名 transcript 规范、nonce 存储和时钟误差处理；跨机器迁移不能直接复制配置完成。

## 备选方案

- **长期 Bearer Token**：开发快，但复制和泄露风险高。
- **mTLS 客户端证书**：安全性强，但个人项目首期的证书签发、轮换和代理配置成本较高，可作为后续企业部署选项。
- **SSH Key**：用途和协议边界不匹配，也会诱导 Relay 直接 SSH 到设备。
