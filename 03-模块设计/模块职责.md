# 模块职责

> [!warning] 当前模块与目标 Runtime 分开阅读
> Run Server、Dispatcher、Runtime PostgreSQL/Valkey、Agent Outbox、Bootstrap、Mobile Web Gateway、Runtime Auth 和 mobile-web HTTP/SSE 主链已经实现。局域网单标签真机闭环已通过，生产容量/公网硬化和 iPhone 迁移仍待实现。

## iPhone App

| 模块 | 负责 | 不负责 |
| --- | --- | --- |
| Workspace | Project/Thread/Turn 交互与结果展示 | Relay 路由和服务端持久化 |
| Relay Client | WebSocket、协议编解码、重连与关联 ID | 日志云存储和用户管理 |
| Diagnostics | Unified Logging、滚动 JSONL、持久上传队列、采样与脱敏 | CoreDevice 命令和任意文件读取 |
| MetricKit Adapter | 接收并持久化 Apple 指标与诊断报告 | 保证 OOM 当下回调 |
| Diagnostics Uploader | 开发/线上共用的批量、重试和容量控制 | 主线程同步网络请求 |

## Mobile Web

| 模块 | 负责 | 不负责 |
| --- | --- | --- |
| Workspace | 移动优先的 Project/Session/Run 交互、结果展示和取消 | Admin 管理、服务端持久化 |
| Runtime Client | 已实现的同源 HTTP/SSE、快照恢复与公网 HTTPS 兼容路径 | 直接连接 Redis、PostgreSQL 或 Agent WSS |
| Mobile Web Gateway | 已实现的单一 Origin、静态资源、版本化路由 allowlist、Runtime/Auth 代理和 SSE 透传 | Token 签发、Scope 授权、Admin、数据库或 Agent WSS |
| Auth Session | 已实现的 Pairing Exchange、内存 Access Token、HttpOnly Refresh Cookie 和多标签页刷新协调 | 在 LocalStorage/IndexedDB 保存长期凭据 |
| Runtime Inspector | 开发期连接状态、请求方向和事件追踪 | 持久保存 Token 或生产审计日志 |

当前 `mobile-web` 已实现 Workspace、真实 Runtime Client、缓存、检查器、Gateway、配对和 Auth Session；发布与真机验收状态见 [[0.2.0 Homebrew 发布候选]]。

## Relay Server

| 模块 | 负责 | 不负责 |
| --- | --- | --- |
| WebSocket Handler | 连接、心跳、帧限制和有界队列 | 保存原始诊断日志 |
| Connection Registry | App/Agent 当前连接和替换 | 用户资料权威存储 |
| Router | 消息方向、目标和离线拒绝 | CoreDevice、SLS 查询、Admin 页面 |
| Protocol | Project/Thread/Turn Schema 与 Fixtures | 诊断和行为 Schema |
| Observability | 产生标准 JSONL 结构化日志 | 直接写 Admin 数据库 |
| Runtime API | Project/Session/Run/Bootstrap/Source HTTP 与 SSE、PostgreSQL/Valkey 协调；公网边缘升级 HTTPS | 提供 Mobile Web 静态资源或信任 Gateway 已授权 |
| Runtime Auth | 已实现的 Pairing/Token、通用 Scope 中间件、独立 `auth` Schema 和 `RuntimeAuthModule` 接口 | Runtime 路由策略、Admin 通用用户管理、Gateway 路由或 Agent 人类身份复用 |

## Mac Agent

| 模块 | 负责 | 不负责 |
| --- | --- | --- |
| Relay Client | 出站连接、重连和消息收发 | Admin 日志摄入 |
| Workspace | 项目允许列表和 Thread 归属 | 接受手机传入任意路径 |
| Codex Adapter | App Server JSON-RPC 和事件转换 | Relay 路由和用户管理 |
| Turn Controller | Turn 超时、中断和状态 | 全局业务任务数据库 |
| Result Collector | Git 文件、Diff 和结果摘要 | 自动提交、推送或部署 |
| Observability | 标准 JSONL、关联字段和资源指标 | SLS 凭据和数据库写入 |

## Admin Server 与 Admin Web

| 模块 | 负责 | 不负责 |
| --- | --- | --- |
| Auth/RBAC | 管理员身份、角色和数据域授权 | Relay WebSocket 身份替代 |
| Users | 用户资料、状态和支持视图 | 从技术日志推导用户权威状态 |
| Behavior | 行为 Schema、查询、漏斗和会话时间线 | 接收自由文本事件名 |
| Diagnostics | 事件查询、事故、采集任务和附件索引 | 在 Web 进程执行任意 Shell |
| Devices | 设备引用、状态和任务授权 | 保存永久硬件标识作为主键 |
| Audit | 查看、导出、修改和设备操作审计 | 与普通技术日志共用删除策略 |
| Query Adapters | 本地/线上 PostgreSQL、SLS 和附件索引 | 将云端凭据暴露给浏览器 |
| Admin Web | 总览、用户、行为、设备、诊断、审计界面 | 直接访问数据库或 CoreDevice |

## Diagnostics Collector

| 模块 | 负责 | 不负责 |
| --- | --- | --- |
| File Tailer | `inode + offset` 增量读取与轮转识别 | 解析业务 Prompt 或输出正文 |
| Batch Sender | 批量、重试、背压和确认后推进游标 | 每条日志同步请求 |
| Device Discovery | 通过公开 CoreDevice 接口发现已配对设备 | 使用私有 API |
| Capture Runner | 执行白名单 App Container、Crash Log、sysdiagnose 任务 | 接受任意命令字符串 |
| Self-observability | 采集延迟、积压、CPU、内存和丢弃数 | 无限内存重试队列 |

## 数据域边界

| 数据域 | Schema | 权限 | 默认存储 |
| --- | --- | --- | --- |
| 用户资料 | 关系模型 | Support/Admin | PostgreSQL |
| 用户行为 | 稳定业务事件 | Product/Support | SLS |
| 技术日志 | 结构化诊断事件 | Engineer | JSONL/SLS |
| 管理审计 | 不可变审计事件 | Admin/Privacy | PostgreSQL + 审计流 |
| 诊断附件 | Manifest + 哈希 | Engineer/Privacy | 本地目录/对象存储 |

共享关联 ID 不代表共享访问权限。页面和 API 必须在每个数据域分别授权和审计。

## 必须保持的边界

> [!warning]
> Mobile Web Gateway 不承担业务鉴权或 Admin；Relay 不承担 Admin 控制面；业务进程不直接写 Admin 数据库；Collector 不执行任意命令；iPhone 不依赖终止回调保证上传；用户资料、用户行为、技术日志和管理审计不得混成同一数据模型。
