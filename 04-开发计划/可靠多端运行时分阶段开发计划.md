# 可靠多端运行时分阶段开发计划

> [!success] 阶段 0-6 已完成 mobile-web 主链验收
> 2026-08-14 已完成 Runtime 主链；2026-08-22 已完成 Gateway 与 Runtime Auth 自动验收；2026-08-23 已通过 iPhone Safari 局域网单标签闭环和本机 Homebrew Runtime 验收。阶段 7 剩余公网/容量硬化与阶段 8 iPhone 迁移仍未实现。

## 1. 仓库边界

1. `iphone-app`、`mobile-web`、`relay-server`、`mac-agent`、`admin-platform` 保持五个独立 Git 仓库。
2. `mobile-web` 只消费 Run Server HTTPS/SSE，不连接 Redis、PostgreSQL、Mac Agent WSS 或 Admin API。
3. Admin Platform 不承载 Runtime 数据库、Dispatcher 或事件持久化。
4. PostgreSQL 是权威事实；Redis 可丢失；Mac Agent 未收到 `durable_ack` 的结果保留在 SQLite Outbox。
5. 本轮不保留 mobile-web Mock/旧接口兼容层；iPhone 继续留在阶段 8 单独迁移。
6. 本轮不实现周期 Reconciler。

## 3. 阶段 0-6 已实现范围

### 契约与数据

- [x] PostgreSQL 仅 7 张 Runtime 业务表，见 [[Runtime PostgreSQL 数据表规范]]。
- [x] Mac Agent SQLite 仅 4 张表；Redis 仅 Result Stream、Session 通知、Agent Presence，见 [[Runtime SQLite 与 Valkey 数据结构规范]]。
- [x] `relay-server/apifox/openapi.json` 覆盖 mobile-web 实际调用的全部 HTTPS/SSE 路径。
- [x] OpenAPI 已同步 Apifox 项目 `8693796`，13 个 endpoint 无错误创建并回读。
- [x] Go module 保持 Go 1.23；没有跨仓源码导入。

### 命令可靠交付

- [x] 创建 Run 时，Run、`session_events` 和 `command_outbox` 在一个 PostgreSQL 事务提交。
- [x] Dispatcher 有界领取 `command_outbox`，Agent 离线时命令留在 PostgreSQL。
- [x] Mac Agent 在调用 Codex 前写 `agent_runs`；相同 `run_id`/`command_id` 不重复执行。
- [x] 取消意图先写 PostgreSQL，再投递 `run.cancel`。

### 结果可靠交付

- [x] Mac Agent 为每个结果分配单调 `agent_sequence`，先写 SQLite `result_outbox` 再发送。
- [x] Relay 写 Redis 成功后返回 `runtime.received_ack`，该 ACK 不删除 SQLite。
- [x] PostgreSQL 以 `(run_id, agent_sequence)` 幂等落库后返回 `runtime.durable_ack`，Agent 才删除已确认 Outbox。
- [x] 同一连接内每 2 秒重放未 durable ACK 的 Outbox；断线重连也从 SQLite 恢复。
- [x] 重复事件不会重复推进 Run 状态或生成 Session Event。

### 多端读取

- [x] Session 快照提供 Run 摘要和 `snapshot_session_sequence`。
- [x] Session SSE 用 `session_sequence` 发现其他客户端创建的新 Run。
- [x] Run SSE 按 `agent_sequence` 合并 PostgreSQL 基线和 Redis 活跃流。
- [x] mobile-web 分别维护 Session Cursor 和各活跃 Run Cursor，异常断开后带最后水位重连。
- [x] 项目下新 Session 通过 `GET /v1/runtime/sessions` 轻量刷新发现，不增加全局 Catalog SSE。

### 初始化与 mobile-web

- [x] mobile-web 在空项目状态且 Agent 在线时触发 Bootstrap，并轮询持久 Sync Job。
- [x] Agent 分批读取 Project/Thread/Turn，批次含 `command_id`、`snapshot_id`、`batch_no`、checksum。
- [x] Run Server 同事务写缺失历史并推进 `sync_jobs`，成功后逐批 ACK。
- [x] Project/Session 导航、历史、Composer、Run、取消、结果视图全部使用真实 API。
- [x] mobile-web 无旧 WebSocket、Redis、PostgreSQL 或 Mac Agent 直连。
- [x] 桌面双标签页与移动视口完成真实浏览器验收。
